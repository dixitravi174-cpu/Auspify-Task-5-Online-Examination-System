# Task 5: Online Examination System

A web-based Online Examination System built using **Python (Flask)**, **SQLite3**, and **Bootstrap 5** for the Auspify Technologies Software Development Internship.

---

## 📌 Project Overview
This platform facilitates secure user authentication/candidate login, interactive multi-question online examination modules, automated score calculation, pass/fail grading, and comprehensive historical score reporting dashboards.

### ✨ Key Features
- **Candidate Registration & Authentication**: Secure onboarding via Candidate Name and Email logging.
- **Dynamic Examination Interface**: Multi-choice question modules covering Python and Computer Science concepts.
- **Automated Score Calculation**: Instant result evaluation, percentage computation, and Pass/Fail status assignment.
- **Score Reports & Analytics Dashboard**: Real-time tracking of total exams taken, average score percentages, and historical audit logs.
- **Persistent Storage**: Lightweight SQLite3 database (`exam.db`).

---

## 🛠️ Tech Stack
- **Backend**: Python 3.12, Flask
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, Bootstrap 5, Jinja2 Templates
